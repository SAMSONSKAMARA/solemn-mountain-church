# Evangelical Solemn Assembly Church — Solemn Mountain Website

This is a responsive church website inspired by the modern structure of the Future Africa Leaders Foundation website, but with original wording, layout, branding and styling for Evangelical Solemn Assembly Church.

## Files
- index.html — main website
- styles.css — design and responsive styling
- script.js — mobile menu and demo contact form
- logo.png — supplied church logo

## Before publishing
Replace the sample ministry/event/gallery content with the church's actual information and photos.

The contact form is currently a front-end demo. To receive messages, connect it to a form-processing service or a server/email backend.

## Publishing
Upload all four files/folders contents to your web host. The file `index.html` should be in the website's main/public folder.
